About KShare

Simple. Secure. Built for the future of cross-platform connectivity.

⚠️ Current Platform Status (v1.4.0)

KShare is currently in its initial release phase and is **EXCLUSIVELY AVAILABLE FOR WINDOWS**. This allows us to ensure maximum stability and a polished feature set before expanding.

The Cross-Platform Vision:

The core application is built with Python and Kivy specifically to ensure true cross-platform compatibility. Our goal is to rapidly expand support to all major platforms to deliver the universal sharing experience.

KShare Development Roadmap

PHASE 1 (Current Focus)

Q1/Q2 2024

  • **Windows Stability:** 100% feature parity and bug fixing on the Windows platform.
  • **Connection Reliability:** Optimization of TCP socket handling and error recovery.
  • **UX Polish:** Finalizing the Kivy UI on desktop (Responsiveness, scaling).

PHASE 2 (Upcoming)

Q3 2024 Target

  • **macOS Support:** First official stable release for Apple devices.
  • **Linux Support:** Official `AppImage` or native packages for major distros (Ubuntu, Fedora).
  • **File Encryption:** Implementing optional basic file transfer encryption (AES-256).

PHASE 3 (Long Term)

Q4 2024 Target & Beyond

  • **Android Mobile App:** First stable release on Google Play (Enables PC to Mobile sharing).
  • **Exotic OS Support:** Testing and packaging for **Ubuntu Touch** and **FreeBSD**.
  • **Multi-File Queue:** Feature to send multiple files or entire folders in a single job.

Technology & Philosophy

The Stack: Built for Speed

  • **Python:** Robust and rapid application development language.
  • **Kivy Framework:** The power behind the universal, native-feeling GUI.
  • **TCP Sockets:** Direct P2P transfer protocol for maximum speed and zero latency.
  • **QR Code:** `qrcode` and `pyzbar` for seamless, IP-free connections.

Our Core Principles

  • **Privacy First:** Absolutely zero cloud upload. File data stays on your local network.
  • **Simplicity:** A minimalist UI focused solely on file selection and transfer status.
  • **Accessibility:** Designed to work perfectly between all major operating systems (Future).
  • **Open Source Mindset:** Transparent, auditable code base (Future intention).
